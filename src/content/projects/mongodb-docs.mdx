I'm an engineer and writer on a team dedicated to building AI-powered 
tooling and automation to modernize our documentation workflow. Our team develops 
agent skills, hooks, and new AI-supported processes that streamline how writers 
work and bring AI directly into the docs process.

Alongside this tooling work, I write documentation for new features on MongoDB's 
core Server product. My work on the documentation team follows a docs-as-code 
workflow: using rST/Markdown language to write documentation, versioning using Git,
and pushing to an open-source monorepo shared across MongoDB's documentation sites, 
where the work is reviewed by writers, engineers, and product managers before publishing.

On the Server Docs team, I co-lead documentation for the Networking & Observability and 
Workload Resilience teams, as well as for the MongoDB Shell, the MongoDB VS Code 
extension, and the MongoDB IntelliJ extension sites.
