A personal passion project blending food, design, and web development.
Designed and implemented a website to track and share the best omakase
restaurants in NYC. Made for my UI Design class at Columbia University,
Spring 2024. Find the code [here](https://github.com/anikaamalhotra-2314/omakase-nyc).

built it from scratch using a Flask app and raw JavaScript, CSS,
