<Intro>

The website you're on right now :) I created my personal website by first
coming up with a design from scatch using Figma, then began implementing it
using TypeScript and React. This was a really fun project for me, because I 
love web development, and I also love making designs and prototypes on Figma. 
For this project, I got to create a site that I felt like really reflected my 
own design style and aesthetic, and also captured my multi-disciplinary interests
between coding, writing, and art (the screenprinted artwork is my own!).

I built this site with the CI/CD flow we use for the MongoDB documentation
site in mind: every project write-up is a version-controlled Markdown file
rather than actual text hard-coded into components, the whole site compiles to static files
in a single build step, and anything malformed (like broken components, type
errors, or invalid Markdown) fails that build instead of silently reaching the page.
I wanted to try building out a similar docs-as-code workflow that I use every day myself, 
since it's so effective for our docs team. 

</Intro>
